Windows Installation

PowerShell is complaining that Python isn't installed!

To install Python, simply navigate to Python's installation page and click the yellow download button.

Once downloaded, launch the wizard and MAKE SURE you check "Add python.exe to PATH". If you do not check the box, Python cannot be executed through the terminal by you or the script.

You can use Python from the terminal without PATH, but you cannot run python, you can only run python.exe. The script uses python.

I've already installed Python but haven't added it to PATH

The easiest way to fix this is by running the installer again, ensuring "Add python.exe to PATH" has been ticked.

Command Prompt is throwing an error when I run some commands

These commands must be run using Windows PowerShell, which is already installed on your system.

MacOS/Linux Installation

Double-clicking launcher_maclinux.sh just opens as text!

This is normal behaviour that can be changed in Settings. Instead, you're going to make only this launcher executable instead of changing a global setting so you don't run potentially malicous code by accident in the future.

Open Terminal and run chmod +x launcher_maclinux.sh

This just makes the script executable which is necessary to run. If it still opens as text, right-click the script in Finder and open it through Terminal.
